# Expense Tracker

A production-oriented SaaS expense tracking application.

## Architecture

- Flutter
- ASP.NET Core
- PostgreSQL
- Keycloak
- Redis
- Apache Kafka
- Docker
- Terraform
- GitHub Actions

## Applications

### Mobile

Flutter application located at:

`apps/mobile/expense_tracker`

### Backend

ASP.NET Core API located at:

`apps/api`

## Architecture Style

The backend follows a modular monolith architecture with:

- Clean Architecture
- Domain-Driven Design principles
- CQRS where appropriate
- Multi-tenancy
- Event-driven integration
